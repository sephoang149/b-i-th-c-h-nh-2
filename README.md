# Bài thực hành 03 - Sổ chi tiêu cá nhân

**Họ tên:** Nguyễn Việt Hoàng  
**Mã sinh viên:** B25DCTV027

## Nội dung

- `part-a-class/`: Sổ chi tiêu dùng Class Component.
- `part-b-hooks/`: Sổ chi tiêu dùng Function Component và Hooks.

## Cách chạy

Vào thư mục của phần muốn chạy, cài dependencies và khởi động Vite:

```bash
cd part-a-class
npm install
npm run dev
```

Hoặc thay `part-a-class` bằng `part-b-hooks`. Với Phần B, cấu hình URL MockAPI trong `part-b-hooks/src/config.js` trước khi sử dụng các chức năng dữ liệu.

Xem README trong từng thư mục để biết chi tiết.
